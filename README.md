# Inferential Statistics Analysis

## Overview

This project demonstrates basic **Inferential Statistics Analysis** using Python.
It analyzes student marks data and performs statistical testing and visualization.

## Features

* Calculate Mean
* Calculate Standard Deviation
* Perform Independent T-Test
* Find Correlation
* Scatter Plot Visualization
* Histogram Analysis
* Correlation Heatmap

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* SciPy

## Installation

Install the required libraries using:

```bash
pip install pandas numpy matplotlib seaborn scipy
```

## How to Run

Run the Python file using:

```bash
python inferential_statistics_analysis_in_dav.py
```

## Dataset

The project uses sample student marks data for:

* Maths
* Science

## Output

The program generates:

* Statistical calculations
* T-test results
* Correlation analysis
* Scatter plot
* Histogram
* Heatmap visualization
